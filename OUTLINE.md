# METAR TAF Practice Reader

The goal for this app is to allow a user to type in an Airport code (i.e. KIPT for Williamsport, PA Airport). You can use aviationweather.gov for the METAR and API data. Fo the look it should have an input fields for the airport and then below show the the METAR and TAF. I would like a toggle for people to select the RAW, Decoded or a side by side option. The decoaded version I would like to use Farenhiet on top and Celius in smaller font below. Show all layers of clouds that are in the METAR or TAF. If there are other features you think that would be helpful for learning how to read a METAR or TAF please add those.
